# Marion Mystery — visual references

Screenshots supplied by the project owner as **visual references** for the Marion Mystery
(murder-mystery multiplayer) mode. More photos will be added to this folder over time.

They are captures from an existing social-deduction game (mostly its VR edition, plus a few
from the 2D original and some fan renders). Use them for **style,
mood, layout and interaction patterns only**. Do not copy that game's character design
(the bean/visor body shape), names, logos, specific cosmetics or artwork. Marion's own bots
and rooms stay the characters and setting.

## What to take from them

- **Rendering:** cel-shaded / flat colour with thick dark ink outlines on every shape;
  simple low-poly forms; soft drop shadows under characters.
- **Palette:** muted teal/slate interiors, warm beige striped wallpaper, a dusty pink accent
  stripe; saturated character colours and bright task highlights (yellow, lime green, magenta)
  against them. Exteriors: purple rock, orange lava glow, snow on roofs.
- **Tasks:** big readable interactive objects — valve wheel with yellow segment ring,
  hand scanner with green/red progress bar, tap-to-upload tablet, targeting grid console,
  green CRT-style diagnostic monitor with hand-drawn line art.
- **Social spaces:** cosy lounge (couch, donut box, water cooler, lockers, punching bag),
  round meeting hall with central table, a wall screen showing the vote ("Who is …?") and a timer.
- **Cosmetics UI:** Shop / Wardrobe tabs, left category list (Featured, Hats, Gloves, Skins),
  4×4 item grid with prices, large character preview on the right, bundles as wide banner cards,
  big pill-shaped Purchase button, currency counter top-right.
- **In-game HUD:** role badge top-left with a progress bar, task checklist (icon, task name,
  room name, 0/2 counter), minimap bottom-left with task markers, chat / emote buttons
  top-right, one big context action bottom-right (Use, Kill with cooldown number, Infect, Vote).
- **Meeting flow:** full-width "Emergency Meeting" banner with hazard stripes and a big red
  button; discussion timer; pointing to accuse; name tags floating over players; vote box.
- **Sabotage:** red alarm banner with a countdown and a pulsing siren icon.
- **Lobby:** room code card with copy button, capacity, preset, privacy toggle, edit/view
  settings, "waiting for players" bar, host label; settings list (roles count, speed, cooldowns,
  meeting/vote times).
- **End-of-round board:** total task progress bar, per-player progress rows, trap / sabotage /
  kill stamps.
